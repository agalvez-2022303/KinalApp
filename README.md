# kinalApp

## Tecnologias utilizadas 
* **Java 21** 
* **SpringBoot 4.0.2**
* **Maven (Gestor de dependencias)**
*  **MySQL(Como sistema gestor de base de datos)**

## Requisitos previos 
Antes de ejecutar la aplicacion debe de tener instalado: 
* JDK 17 O superior
* Maven Instalado 
* Una instancia activa en mysql
